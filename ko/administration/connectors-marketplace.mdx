# Connectors & Marketplace

Connector는 연결 family이고 Source Pack은 선언형 integration content입니다. 둘 다 runtime 실행 단위가 아닙니다.

현재 개발 브랜치에는 Manifest v2, unified registry, install/upgrade/rollback/uninstall, validator, secret scan, digest/signature, trusted key, license/provenance, Connector Harvester, AI Connector Builder core, Marketplace UI, private/remote registry, offline signed bundle 경로가 구현되어 있습니다.

다만 이 사이트는 해당 기능을 **tag-proven stable**이라고 표현하지 않습니다.

Package 설치만으로 Credential 생성, Stream enable, running Stream 변경, checkpoint 진행이 일어나서는 안 됩니다.
