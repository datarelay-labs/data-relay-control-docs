# 운영 개요

일상 운영은 Dashboard/Streams에서 상태를 보고 문제가 있는 Stream/Route/Destination으로 drill-down하는 흐름이 기본입니다.

Runtime은 delivery log, route outcome, snapshot/analytics, checkpoint, schema drift, governance/audit evidence를 남깁니다.

개발 브랜치에는 Data Flow Troubleshooter, Safe Change, Connector/API Health, Test Before Apply, Environment Promotion이 구현되어 있으며 기존 evidence/configuration을 재사용합니다.
