# 라이선스

Data Relay Control은 **오픈소스가 아니라 Source Available 소프트웨어**입니다. 특정 파일 또는 서드파티 구성요소에 별도 라이선스가 명시된 경우를 제외하고, 현재 배포본에는 **Data Relay Source Available License 1.0**이 적용됩니다.

<Note>
법적 효력이 있는 기준 문서는 [`datarelay-labs/gdc-platform` 저장소의 LICENSE](https://github.com/datarelay-labs/gdc-platform/blob/main-v2/LICENSE)입니다. 이 페이지는 이해를 돕기 위한 요약이며 LICENSE 전문을 대체하지 않습니다.
</Note>

## 무료로 허용되는 사용

다음 용도로 Data Relay Control을 무료로 사용할 수 있습니다.

- 개인 사용
- 교육 및 비상업적 연구
- 평가 및 테스트
- 기업·기관의 자체 업무 목적 사용
- 허용된 목적을 위한 내부 소스 코드 수정
- 고객이 직접 통제하고 사용하는 고객 소유 환경에 설치
- 고객 소유 환경을 대상으로 한 설치, 연동, 마이그레이션, 유지보수, 교육, 기술지원 서비스

고객 환경에 설치하는 경우에도 Data Relay 자체를 재판매하거나 관리형 서비스로 제공해서는 안 됩니다.

## 제품화는 허용되지 않습니다

Data Relay Labs의 별도 서면 상업 라이선스가 없는 경우 다음 행위는 허용되지 않습니다.

- Data Relay 재판매 또는 서브라이선스
- 원본 또는 수정본을 별도 상용 제품으로 재배포
- Data Relay 또는 소스 코드의 상당 부분을 상용 제품·어플라이언스에 OEM, 임베딩, 번들링 또는 통합
- 이름을 변경하거나 리브랜딩·화이트라벨·fork하여 상용 제품화
- Data Relay 기능 자체를 SaaS, MSP, Hosted, Shared, Multi-tenant 서비스로 제3자에게 제공
- 소스 코드 또는 상당 부분을 이용해 Data Relay와 경쟁하거나 실질적으로 대체 가능한 제품·서비스를 개발, 개선 또는 유지
- 저작권, 라이선스, 출처, 상표 고지 제거 또는 은폐
- 본 프로젝트를 OSI 승인 오픈소스 소프트웨어라고 표시

## 사용 예시

| 사용 방식 | 허용 여부 |
|---|---|
| 회사 자체 서버에서 Data Relay 사용 | 허용 |
| 회사 내부 환경에 맞게 소스를 수정하여 사용 | 허용 |
| 고객 소유 서버에 설치하고 고객이 직접 운영 | 허용 |
| 고객 소유 배포 환경에 대해 설치·마이그레이션·지원 비용 청구 | 허용 |
| Data Relay를 fork하고 이름을 바꿔 다른 제품으로 판매 | 금지 |
| Data Relay 코드를 상용 보안·데이터 제품에 포함 | 금지 |
| Data Relay 기능을 SaaS 또는 MSP 서비스로 판매 | 금지 |
| 소스를 이용해 경쟁·대체 제품을 개발 또는 개선 | 금지 |

## 별도 상업 라이선스

다음 권리가 필요한 경우 Data Relay Labs의 **별도 서면 상업 라이선스**가 필요합니다.

- 재판매
- OEM / 임베딩
- 화이트라벨
- 상업적 재배포
- 파생 상용 제품
- SaaS / MSP / Hosted 서비스
- 경쟁 제품 개발
- 기타 제품화

## 왜 Open Source가 아니라 Source Available인가

이 라이선스에는 제품화, 경쟁 제품, SaaS/MSP 제공에 대한 사용 제한이 있습니다. 이러한 제한은 OSI Open Source Definition과 맞지 않으므로 Data Relay Control은 **Open Source가 아니라 Source Available**로 표시합니다.
