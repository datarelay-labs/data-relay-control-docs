# Governance

Governance는 별도 Compliance 제품이 아니라 선택적 **Data Control capability**입니다.

사용자는 “민감한가?”, “어떻게 보호할까?”, “전달해도 되는가?”, “위반 시 무엇을 할까?”를 정의합니다.

현재 UI에는 Governance Dashboard, Operations, Violations, Quarantine, Audit, Approvals, Replay, Notifications, Workspace가 있습니다.

Stream에 공통 intent를 두고 목적지별 실제 처리는 Route-aware하게 적용할 수 있습니다.

Governance Workspace는 일부 workflow에서 read-only MVP이며 Route 수가 많아지면 API fan-out 비용이 커질 수 있습니다.
